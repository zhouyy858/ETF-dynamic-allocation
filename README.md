## 策略作用

- **目标**：回撤<10% 约束下最大化长期复合收益——熊市靠红利/现金收缩回撤，牛市放大成长弹性；长期主义者、钱永不离开市场。
- **标的**：159232 自由现金流ETF（A价值防御）、515100 红利低波100ETF（A红利底仓）、159941 纳指100ETF（海外AI成长）、513500 标普500ETF（美股均衡）、159952 创业板ETF（A成长弹性）。
- **机制**：双市场（A股/美股）9 维均线打分 → 状态 0-9 动态权重；叠加 **5 层生效风控**（结构闸门/快刹车/深熊锁/QDII 溢价门控/跨市场相关性风控）。`vol_target`、`dd_eq_cap` 经消融证伪已删除（2026-09-18），`speed_brake` 已关但代码保留可回退。

## 前提与设计原则（v28~v30 依据）

> 四项前提由用户给出，是参数调整依据。**方向由前提决定，回测只做证伪**——历史奖励的行为若与前提冲突，宁可牺牲历史 Calmar 也不迁就。

1. **美股长期向好** → US 底仓 7.5%→**10%**（各 5%）、溢价再平衡上限 0.5→**1.0**（高溢价期弹性全额转低溢价标普，同一美元 beta 买更便宜载体）。
2. **创业板大幅波动、整体震荡（v30 起弱化）** → 成长拆分 bull 35%→28%（v30 回吐一半至 **30%**）、bear 45% 不变。2026-06/07 创业板 ±7% 剧烈震荡实证该前提。v30 弱化为中性：**28-32% 为平滑平台，33% 是孤峰（Cal 1.18→1.61 跳跃）严禁触及**。
3. **未来是 AI 科技的天下** → 纳指100 超配：bull **65%**、bear **40%**（组合内最纯粹 AI 载体；高溢价期全额转标普、AI 敞口不消失不付溢价风险）。
4. **红利低波周期转换时间长** → CN 红利底仓 0→4%（深熊锁中也持有收息）；v30 降为 **2%**（各 1%）——2015/2016 CN 熊承压减半，是回撤破线修复主因（CN 底仓轴 1-4% 平滑，2% 是回撤<10% 上限）。

**版本映射**：前提①-④ → v28（CN 底仓 4%、创业板 28%）→ 前提③加强 → v29（纳指超配）→ **v30 中间态（前提②④弱化但全部保留、回撤压回 10% 内）**。v27 为纯历史拟合最优（proxy Cal 1.55），v28/v29 为前提一致但破验收线，v30 = 「前提全生效 + 回撤达标」。

## 为什么 v30 比 v27 历史数字"差"（前提驱动代价，简）

- v27 的 proxy Cal 1.55 大量来自创业板历史三轮大牛（2015/2019/2024）——前提②认为不可外推，降权后历史收益不再计入（proxy -0.20pp）；US 底仓 10% + CN 底仓 2% 在下跌路径持续暴露，是前提①④"穿越周期"的代价（MDD -6.96%→-9.92%）。
- real 窗口 v27 吃满 2025 创业板 +88%，v28/v29 主动少持（2026-06/07 -18.8% 剧烈震荡段少亏：段内 DD -3.35% vs -4.01%）——一增一减正是前提②的兑现。
- 前提③（AI 科技）是"免费"方向：纳指超配双窗口 CAGR 均升（v28→v29 +0.13/+0.40pp）、OOS 1.14→1.15，代价仅美股熊段 MDD +0.1~0.2pp。
- **结论（诚实边界）**：前提成立则 v30 未来期望高于 v27（v27 依赖不可重复的创业板牛市、扰动敏感 14/112）；三版配置均保留（`final_cfg_v27/29/30.json`）可随时回退。

## 使用方法

```bash
python3 scripts/run_backtest.py                      # 完整回测（默认 v30）：DYN vs B1-B7 + 分阶段 + 仓位现状 + 终端 ASCII 图
python3 scripts/run_backtest.py <cfg.json> <tag>     # 自定义参数
python3 scripts/audit_lookahead.py                   # 未来函数审计（口径对照 + 旧口径复现校验 + v20-v30 断言）
python3 scripts/stress_test.py                       # 压力测试（牛市/震荡/三轮熊市/跨境共振合成）
python3 scripts/audit_robustness.py references/final_cfg_v30.json v30   # 防过拟合：参数扰动审计
python3 scripts/search_v22.py S|F|P|G                # 全参数重训各阶段（可复现）
python3 scripts/daily_automation.py                  # 日报：拉数→日报→更新README→推送（Codex 定时任务 每交易日 09:00）
python3 scripts/week_retrain.py                       # 每周重训：拉数→全参复检→三关验证→升级/维持→推送（Codex 定时任务 每周五 16:00）
```

输出写入当前目录 `out/`；图表为终端 ASCII。每日日报（信号/仓位/目标/调仓动作/QDII 溢价/组合表现）保存到 `~/ETF策略日报/reports/`，macOS 通知 + 可选 Server酱/Bark 推送。

## 自动化（Codex 定时任务触发，已停用 launchd）

- **09:00 日报**：`daily_automation.py` 拉取最新净值 → 生成日报 → 更新 README 当前持仓段 → 推送。
- **周五 16:00 收盘重训**：`week_retrain.py` 拉取当日收盘数据 → 全参数复检（proxy/real 双窗口）→ 三关验证（双窗口同向改善 + 平台平坦 + OOS 不劣化）→ 通过则升级版本并留档，否则维持 v30 → 更新日报/README → 推送。
- 防过拟合纪律：拒绝孤峰/单窗口改善；每周只做邻域复检而非自由网格重挖；参数只有过三关才升级。
- 复检日志：`~/ETF策略日报/logs/retrain_YYYYMMDD.log`；推送凭据 `~/.config/etf_skill/git_token`（chmod 600，不入库）。
- **Codex 定时任务参考 prompt**：`拉取ETF最新数据重建面板→设计并运行新参数/方案搜索（候选必须过三关：proxy+real双窗口同向改善、平台平坦、OOS不劣化，禁止孤峰）→通过则升级版本配置否则维持v30并记录→更新README/SKILL.md→git commit+push→汇报结论和当前仓位。`
