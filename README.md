## 策略作用

- **目标**：回撤<10% 约束下最大化长期复合收益——熊市靠红利/现金收缩回撤，牛市放大成长弹性；长期主义者、钱永不离开市场。
- **标的（v43 成交）**：563020 中证红利低波 ETF（A 红利底仓，信号槽对应 515100）、159941 纳指100 ETF、513500 标普500 ETF、159952 创业板 ETF。自由现金流 159232/159222 **不再持有**；`exclude` 在信号与目标权重两端同时生效。
- **机制**：双市场（A 股/美股）9 维均线打分 → 状态 0-9 动态权重；保留结构闸门、快刹车、深熊锁、QDII 溢价门控/倾斜、3 周触底冷却，并叠加单资产急跌刹车、120 日绝对动量、20 日波动率闸门。相关性风控、溢价轮动、美股轮动、regime、恢复斜坡、re-entry 等低贡献层关闭；`vol_target`、`dd_eq_cap` 已于 2026-09-18 消融后删除。

## 前提与设计原则（v28~v30 依据）

> 四项前提由用户给出，是参数调整依据。**方向由前提决定，回测只做证伪**——历史奖励的行为若与前提冲突，宁可牺牲历史 Calmar 也不迁就。

1. **美股长期向好** → US 底仓 7.5%→**10%**（各 5%）、溢价再平衡上限 0.5→**1.0**（高溢价期弹性全额转低溢价标普，同一美元 beta 买更便宜载体）。
2. **创业板大幅波动、整体震荡（v30 起弱化）** → 成长拆分 bull 35%→28%（v30 回吐一半至 30%）、bear 45% 不变。2026-06/07 创业板 ±7% 剧烈震荡实证该前提。v43 沿用 v41 的 **36%**：继续提高到 37~38% 可多约 0.05~0.10pp CAGR，但 proxy MDD 加深 0.1~0.2pp、Calmar 下降，未采用。
3. **未来是 AI 科技的天下** → 纳指100 超配：v43 bull **57%**（v30 63%、v40 61%）、bear **40%**（组合内最纯粹 AI 载体；高溢价期全额转标普、AI 敞口不消失不付溢价风险）。
4. **红利低波周期转换时间长** → CN 红利底仓 0→4%（深熊锁中也持有收息）；v30 降为名义 **2%**（两槽各 1%）；v41/v43 排除 159232 后，成交端只剩 563020 的 **1%** 有效底仓。

**版本映射**：前提①-④ → v28（CN 底仓 4%、创业板 28%）→ 前提③加强 → v29（纳指超配）→ **v30 中间态（前提②④弱化但全部保留、回撤压回 10% 内）**。v27 为纯历史拟合最优（proxy Cal 1.55），v28/v29 为前提一致但破验收线，v30 = 「前提全生效 + 回撤达标」。

## 核心执行规则（硬性约束）

1. **周五调仓、1 笔当日收盘成交（v22 起）**：只用截至前一日收盘数据决策（无未来函数）；目标缺口 1 笔当日收盘成交（滞回 0.66/0.24 + 2 周周三确认，45 组网格实证 1 笔胜出）；计划不重叠；紧急风控任意交易日触发并当日生效。
2. **底仓（v43）**：国内红利底仓 **有效 1%**（只剩 563020，深熊锁存活、**不择时不清仓**；配置的 `floor_pct.cn=2` 在两槽平分后再排除 159232，因此成交端只剩 1%）、海外 159941+513500 合计 **12%**（各 6%）固定不动。状态 7/8/9 成长上限 **73/93/89**。原 159232 槽已排除，成交端不再使用 159222。
3. **现金管理（v37）**：闲置现金 **100% 国债ETF 511260**（10Y）。v24 至 v30 是 25% 逆回购 + 75% 511010，`final_cfg_v30.json` 仍可回退。511260 在 2017-08-24 之前用 511010 拼接，样本里没有 2013 钱荒，多出来的收益是久期不是择时。资金留证券账户场内执行，**不放支付宝场外货基**（赎回 T+1 + 跨账户划转破坏紧急风控当日生效）。
4. **风控（v43，以 `final_cfg_v43.json` 为准）**：结构闸门（破 100 日线→该市场成长弹性×0）；快刹车（CN 回撤>7%/US>13% 且破 SMA20→成长仓×0.05/×0.12）；深熊锁定（CN>18%/US>24%→弹性全清只留底仓；解锁：回撤收窄至 14%/15% 内或站上 SMA120 且双均线多头）；QDII 溢价门控（溢价>5/8/12%→海外成长弹性×0.40/0.20/0.08，T-2 口径）；单资产 5 日急跌 -8%→该资产弹性×0.30；120 日绝对动量为负→成长弹性×0.80；20 日年化波动 30/40/50%→×0.86/0.72/0.48。**已关**：相关性风控、溢价轮动、美股轮动、regime、恢复斜坡、re-entry、speed_brake、防御动量。`vol_target`、`dd_eq_cap` 已删除。
5. **QDII 现实风险**：溢价>3% 注意、>5% 买入暂缓（T-2 口径决策）；**相对溢价倾斜（v25）**：纳指/标普溢价差>2pp 时高溢价品种弹性（最多 50%）转投低溢价品种；**溢价门控削减增强（v26）**与倾斜并行——门控管总量、倾斜管内部分配；数据链路腾讯场内价 + IOPV 双源校验。
6. **触底冷却（v40 引入，v43 保留）**：任一槽位目标从地板以上落到地板（深熊锁/结构闸门/快刹车打到底仓均计入），该槽位至少冷却 **3 周**，期间只能停留在地板；冷却结束后才允许按打分恢复。作用是降低“打到底→立刻回补→二次下跌”的甩鞭损耗。

## 为什么 v30 比 v27 历史数字"差"（前提驱动代价，简）

- real 窗口 v27 吃满 2025 创业板 +88%，v28/v29 主动少持（2026-06/07 -18.8% 剧烈震荡段少亏：段内 DD -3.35% vs -4.01%）——一增一减正是前提②的兑现。
- 前提③（AI 科技）是"免费"方向：纳指超配双窗口 CAGR 均升（v28→v29 +0.13/+0.40pp）、OOS 1.14→1.15，代价仅美股熊段 MDD +0.1~0.2pp。
- **结论（诚实边界）**：前提成立则 v30 未来期望高于 v27（v27 依赖不可重复的创业板牛市、扰动敏感 14/112）；三版配置均保留（`final_cfg_v27/29/30.json`）可随时回退。
