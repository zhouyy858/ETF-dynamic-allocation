## 设计前提

> 方向由前提决定，回测只负责证伪；不因为某个历史窗口收益更高就推翻长期假设。

1. 美股长期向好：US 底仓保持 11%，高溢价时在纳指与标普之间倾斜。
2. 创业板高波动、长期震荡：创业板只占成长桶 36%，不押单一成长风格。
3. AI/科技长期占优：纳指仍为成长桶 57%，但受溢价门控约束。
4. 红利低波穿越周期：国内红利保留有效底仓 4%，深熊锁中保留底仓以上红利的 15% 作为防守腿。
5. 红利与创业板存在跷跷板：创业板深熊时，不清零红利防守腿。
6. 科技与海外存在联动：海外科技打分采用纳指120 1.5 / 标普120 1 / 纳指60 0.5，降低重复计分。

## 执行规则

1. **周五净额调仓**：正式统计只用截至前一交易日收盘的数据，无未来函数。
2. **尾盘执行**：周五 09:00 生成清单，14:45 检查行情与 QDII 溢价，14:50–14:57 用限价单完成同一净额目标。
3. **同日完成**：卖出与买入在周五同日完成，不拆成“周四卖、周五买”；紧急风控可在任意交易日触发。
4. **交易门槛**：单边费用按万 5；目标缺口小于 **3.5pp** 不交易；触底后冷却 **3 周**。
5. **QDII 执行**：下单前检查 IOPV；溢价 >5% 时买入暂缓，溢价 >8%/12% 时进一步削减。
6. **现金管理**：资金留在证券账户场内，不使用支付宝等场外货基。

## 风控

- **结构闸门**：SMA80/SMA100/SMA120 多数投票，至少两个窗口跌破才关闭成长弹性。
- **快刹车**：CN 回撤 >7%、US >13% 且破 SMA20 时，成长仓降至 ×0.05/×0.12。
- **深熊锁**：CN 回撤 >15%、US >21% 时清空对应市场弹性，只留底仓；CN 保留 15% 红利防守腿。
- **QDII 溢价门控**：T-2 绝对溢价 >5%/8%/12% 时，海外成长弹性降至 ×0.40/×0.20/×0.08。
- **相对溢价倾斜**：纳指与标普溢价差 >2pp 时，向低溢价品种转移部分弹性。
- **其他过滤**：单资产 5 日急跌 8% → ×0.20；120 日动量为负 → ×0.90；20 日年化波动 >30%/40%/50% → ×0.86/×0.70/×0.48。
