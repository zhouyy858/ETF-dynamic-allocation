# ETF 动态配置策略（v47）

四只 ETF + 现金的长期动态配置策略。每周五使用前一交易日收盘信号决策，周五尾盘完成一次净额调仓；不使用场外联接基金。

## 核心配置

- **成交标的**：512890 红利低波、159941 纳指100、513500 标普500、159952 创业板。
- **底仓**：国内红利有效 4%，海外 11%（纳指、标普各 5.5%）。
- **现金层**：闲置现金 100% 配置 511260（10 年国债 ETF）。
- **成长拆分**：状态 3–9 为 创业板/纳指/标普 = 36/57/7；状态 0–2 为 45/40/15。
- **状态仓位**：9 维均线打分映射到 0–9 状态；状态 7/8/9 成长上限分别为 73/93/89。
- **执行约束**：单边费率万 5；目标缺口小于 3.5pp 不交易；触底后冷却 3 周。
- **v47 改动**：红利低波由 563020 改为 512890；结构闸门由单一 `gate_win=100` 改为 SMA80/100/120 多数投票。

## 风控

1. **结构闸门**：SMA80/100/120 多数投票；至少两个窗口跌破才关闭成长弹性。
2. **快刹车**：CN 回撤超过 7%、US 超过 13% 且破 SMA20 时，成长仓降至 ×0.05/×0.12。
3. **深熊锁定**：CN 超过 15%、US 超过 21% 时清空对应市场弹性，仅留底仓。
4. **红利防守腿**：CN 深熊锁中保留底仓以上红利弹性的 15%，避免红利与创业板同时清零。
5. **QDII 溢价门控**：T-2 绝对溢价超过 5%/8%/12% 时，海外成长弹性降至 ×0.40/×0.20/×0.08；纳指与标普溢价差超过 2pp 时向低溢价品种倾斜。
6. **其他过滤**：单资产 5 日急跌 8% 降至 ×0.20；120 日动量为负时 ×0.90；20 日年化波动超过 30%/40%/50% 时 ×0.86/×0.70/×0.48。

## 执行纪律

- 正式统计只使用截至前一交易日收盘的信号，避免未来函数。
- 周五 09:00 生成清单，14:45 检查行情与 QDII 溢价，14:50–14:57 用限价单完成同一净额目标。
- 卖出与买入同日完成，不拆成“周四卖、周五买”。
- 紧急风控可在任意交易日触发。
- 下单前检查 IOPV；高溢价 QDII 不追价。

## 边界

- 历史业绩不代表未来；策略是纸面研究，不执行下单。
- QDII 场内价数据从 2015 年中才有，更早区间使用代理序列。
- 511260 存在久期风险；股票端风控不会自动覆盖债市回撤。
- v45 的 CSCV/PBO 为 83.8%，说明高相关候选族中的选参不稳定，不能把历史 Calmar 当作未来保证。
