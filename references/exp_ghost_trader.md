# 幽灵交易系统纸面回测

**结论：预注册默认参数（20 日新高、RSI(9)<70、幽灵过滤开启）未通过三关，不能替换 v30。** proxy 年化 11.15%，与 v30 的 11.11% 接近，但最大回撤 -21.88%（v30 -9.91%），Calmar 0.51 对 1.12。real 窗口年化 -7.21%（v30 23.70%），OOS 年化 0.63%（v30 9.73%）。本实验只读 `final_cfg_v30.json`，没有改默认策略，也没有实盘下单。

数据 2014-06-23 → 2026-11-06（proxy 3018 个交易日；real 373 日；OOS 1175 日）。费用单边万 5。空仓现金 = 25% 逆回购 2.2% + 75% 国债 ETF 511010。信号当日收盘确认，下一交易日收盘成交，成交当日收益仍归旧仓。

## 规则

- 只做多。空头规则没有实现。
- 入场同时满足：EMA9 > EMA19，RSI(9) 未超买，收盘创前 N 日新高。出场：收盘跌破前 20 日最低收盘。N 与 RSI 阈值见敏感性表，出场窗口固定 20。
- 影子账户每笔信号都做。真实账户只在最近一笔**已平**影子交易净盈亏 < 0 时接下一次信号。还没有任何已平影子交易时，真实账户不做。净盈亏含双边万 5。
- 组合权重 = 当前有真实持仓的 ETF 等权，其余现金。持仓集合不变时不每日再平衡。
- 对照：同一规则关掉幽灵过滤、v30（同一窗口、引擎原样）、五只等权买入持有（引擎 B7，建仓后不再平衡）。

## 主结果

换手/年 = 全样本 Σ|Δ权重| ÷ 年数（与引擎的换手同口径，再按年化）。胜率、平均持仓只统计已平真实交易，盈亏是该 ETF 自身的双边费用后收益，不是组合贡献。在场 = 当日收益由持仓计提的天数占比。

## 幽灵过滤本身

下表是默认参数下，打开过滤相对关掉过滤的差。过滤的设计假设是：上一笔影子亏损之后，下一笔更值得做，所以真实胜率应高于影子胜率。

| 窗口 | ΔCAGR | ΔMaxDD（正=回撤变浅） | ΔCalmar | 真实笔数 / 影子笔数 | 真实胜率 | 影子胜率 |
|---|---:|---:|---:|---:|---:|---:|
| proxy | 4.84% | 14.08% | 0.33 | 109/215 | 49.54% | 47.44% |
| real | -15.96% | 5.60% | -0.80 | 9/24 | 44.44% | 50.00% |
| OOS | 0.71% | 3.88% | 0.03 | 44/84 | 50.00% | 42.86% |

proxy 上，费用把毛利由正打成净亏的影子交易有 2 笔（过滤用的是净盈亏）。真实交易占影子交易的比例：proxy 109/215，real 9/24，OOS 44/84。

胜率没有按过滤的假设抬起来。proxy 真实胜率 49.54%，影子 47.44%，差约 2 个百分点；109 笔、胜率五成时标准误大约 4.8 个百分点，这个差看不出来。real 窗口真实胜率 44.44%，低于影子的 50.00%（只有 9 笔）。OOS 真实 50.00%、影子 42.86%，样本 44 笔。proxy 上 Calmar 从 0.18 到 0.51，对应的是在场从 90% 降到 73%，少挨了几段回撤，不是胜率变高。real 窗口过滤把 Calmar 从 0.38 打到 -0.42。

## 三关

判定与 `scripts/exp_opt31.py` 里 v30 的升级线相同，基准是本次用同一数据重跑的 v30，不是 README 里的旧打印数。

1. **双窗口**（proxy 与 real 的 Calmar 都要 ≥ v30 + 0.15，且 proxy MDD 浅于 -10%、real MDD 浅于 -4.1%）：未过。proxy ΔCalmar -0.612 < +0.15；real ΔCalmar -6.737 < +0.15；proxy MDD -21.88% 未优于 -10%；real MDD -17.26% 未优于 -4.1%
2. **平台**（默认点的四个单轴邻居里，至少 3 个双窗口 ΔCalmar > 0.10，且 N 轴、RSI 轴相邻 Calmar 落差不超过 0.5）：未过。邻居中双窗口 ΔCalmar>0.10 的只有 0 个，需要 ≥3
3. **OOS**（proxy 自 2022-01-04 起，指标用得到之前的价格，但影子盈亏状态从零开始，与 v30 重开状态变量的方式一致。Calmar 不得低于 v30 OOS − 0.05）：未过。OOS Calmar 0.031，v30 1.259，差 -1.228（低于 v30 超过 0.05 即未过）

18 格里没有任何一格同时满足第一关和第三关。不存在一个『只是没被选为默认』的隐藏赢家。

## 过拟合与做不到的事

- 默认参数是任务给定的，不是这 18 格里挑出来的。即便如此，N 与 RSI 各只有三个点，平台很窄；极差大就说明收益对参数敏感，不能外推。
- 真实交易次数少。proxy 109 笔的胜率标准误大约 5 个百分点，过滤相对影子只高约 2 个百分点；real 窗口过滤后的胜率低于影子。过滤没有表现出它声称的『亏完下一笔更值得做』。
- 『上一笔亏了下一笔就做』假定交易盈亏负相关。趋势突破没有这个结构。本样本里它主要是少做交易、降低在场时间；这个效果在 proxy 上看起来减了回撤，在 real 窗口是减了收益。
- real 窗口大约一年半，并且落在 2025–2026。这个窗口的 Calmar 不能当成系统的长期水平。
- 五只里挑 Calmar 最高的一只是样本内选择。宽基 510300 是同一规则的外部对照，不是第二个优化目标。
- 等权于『当前有仓的标的』意味着只持有一只时仓位是 100%。回撤里有很大一部分是集中度，不是过滤能消掉的。
- 回测没有涨跌停、QDII 溢价、停牌顺延。万 5 是佣金加滑点的合并假设，和 v30 相同，不是券商账单。
