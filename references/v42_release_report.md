# v42 发布记录（2026-11-11，进攻版）

> 纸面研究，不执行下单。数据截至 2026-11-10。用户明确选择“无红利低波 + 进攻版”作为 v42 生产默认；上一默认 v41 保留回退。

## 1. 结论

v42 在完全移除红利低波 `515100/563020` 与自由现金流 `159232/159222` 后，把原防御权重全部转为成长，海外底仓提高到 14%，创业板占成长桶 40%，CN 快刹车阈值设为 8%，开启组合级速度刹车，关闭 US 轮动、资产急跌刹车与 20 日波动率闸门。

| 口径 | v41 | v42 进攻版 | 差异 |
|---|---:|---:|---:|
| proxy CAGR | 13.40% | **15.23%** | +1.83pp |
| proxy MDD | **-7.26%** | -8.66% | 恶化 1.40pp |
| proxy Calmar | **1.845** | 1.759 | -0.086 |
| real CAGR | 29.90% | **31.00%** | +1.10pp |
| real MDD | **-4.53%** | -5.23% | 恶化 0.70pp |
| real Calmar | **6.604** | 5.923 | -0.681 |
| OOS CAGR | 12.69% | **13.58%** | +0.89pp |
| OOS MDD | **-7.00%** | -8.33% | 恶化 1.33pp |
| OOS Calmar | **1.815** | 1.631 | -0.184 |

结论：v42 是明确的**收益优先档**，不是 v41 的风险调整升级。proxy 收益提高 1.83pp，但全历史、真实窗口和 OOS 的回撤都更深。

- WFO 测试 2022-2026：`13.58% / -8.33% / Cal 1.631`（v41 `12.69% / -7.00% / Cal 1.815`）。
- 104 次参数扰动中 Calmar 恶化>10% 为 `6/104`（v41 `4/104`）。
- 20 日块自助 2000 次：`P(Cal<1)=15.35%`，Cal 5% 分位 `0.772`，MDD 5% 分位 `-15.49%`，CAGR 中位 `15.13%`。尾部 Calmar 比 v41 好，但 MDD 尾部更差。

## 3. 新增资产研究

数据：`511380` 可转债 ETF、`511360` 短融 ETF（按“短融通”理解为短融 ETF），均截至 2026-11-10；上市前用 511260 拼接。

> 口径提示：旧手册曾把 `511380` 写作“国开债”，与本次用户口径“可转债”冲突。下载序列年化波动约 10.1%、MDD -17.5%，特征与可转债一致而不是国开债；正式采用前必须核对基金代码与名称。本次实验不采用该资产，因此不影响 v42 默认配置。

### 3.3 去掉标普 513500

| 配置 | proxy CAGR/MDD/Cal | real CAGR/MDD/Cal | OOS Cal | 判断 |
|---|---:|---:|---:|---|
| v42 保留标普 | 15.23% / -8.66% / **1.759** | 31.00% / -5.23% / **5.923** | **1.631** | 基准 |
