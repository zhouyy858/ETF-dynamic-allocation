# 纸面：v47 去掉国内权益，只留美股 ETF 与现金

纸面研究，不下单，不改默认。default remains v47（`references/final_cfg_v47.json`，发布提交 `f10d91b`）。本文件不替换默认，也不合并。

## 结论

七个预注册的「只有 159941、513500 和现金 511260」候选，三关全部失败。proxy、real、OOS 的 Calmar 都低于同一数据上重跑的 v47。没有任何一格同时做到 proxy CAGR ≥ 15% 且 |MDD| < 10%。

不升级，不改默认。默认仍是 v47。

## 口径

同一官方引擎，没有新下载数据。面板最后一天是仓库里已有的 **2026-11-12**。

- 引擎：`scripts/engine.py` 的 `run_backtest`，`strict=True`，`accrual_mode=pre`，单边费用万 5（`FEE=0.0005`）。
- 损益：`scripts/run_backtest.py` 的 `exec_panel(..., "price")`。主表是场内价。净值口径另表，不和场内价混比。
- 调仓：周五、`signal_lag=1`、一笔、`min_delta=0.035`。现金 100% `511260`。
- Sharpe 用 `evaluate()` 的默认无风险利率 1.8%。现金收益来自 511260，不是这 1.8%。
- 训练段、OOS、real 都是冷启动，和 `scripts/exp_v47_validate.py`、`scripts/run_backtest.py` 一样，不是从全历史净值上切下来的。

## 权重怎么改派

v47 成交端是 512890（由 515100 换券）、159941、513500、159952，外加被排除的 159232。配置里 `floor_pct.cn=8` 两槽平分后，159232 已排除，有效国内底仓是 512890 的 **4%**。牛市成长拆分是 159952:159941:513500 = **36:57:7**，熊市 **45:40:15**。`state_map` 的第二列是红利防御弹性。

本次书只保留 159941、513500、511260。不新增标的。512890 和 563020 都不进成交：`instrument_swaps` 清空，515100 槽进入 `exclude`。

A0 是唯一的干净消融，规则事先写死：

1. **创业板成长份额进美股，按原来的纳指/标普比例放大。** 配置里牛市仍写 0 / 0.57 / 0.07、熊市仍写 0 / 0.40 / 0.15，159952 显式为 0。引擎对未排除的权重归一化（`strategy.py` 初始化里对 `growth_split_*` 的处理）。实际成交比例是牛市 **89.0625% / 10.9375%**，熊市 **72.727% / 27.273%**（0.57/0.64 与 0.40/0.55）。
2. **有效 4% 国内底仓进现金。** `floor_pct.cn=0`，`floor_pct.us` 保持 **11%**（159941 与 513500 各 5.5%）。引擎的底仓是两只美股平分，没有按 57:7 拆底仓的参数，所以 A0 不动这个机制。
3. **防御列进现金，不并进美股。** 159232 和 515100 都排除后，防御拆分为空，`tot_d==0`，引擎不会把防御预算改派到美股。`lock_defense_keep=0.15` 还在配置里，但没有防御弹性可留。

F15 才把那 4% 加到海外底仓（11% → 15%，各 7.5%）。Dtog 才把防御列整列加进成长列。这两格是对照，不是 A0。

国内槽的日终权重在全部窗口、两种口径上绝对值最大为 **0**。因此没有改引擎。排除名单会把底仓清零，并在 `_base_target` 末尾把排除槽写成 0；后面的波动率、动量、冷却只朝底仓收缩，0 仍然是 0。

仍会读到 A 股、但不会买 A 股的部分，保持 v47 原样：

- `score_mode=cn_lead` 仍用沪深 300 和创业板给分，用来决定美股仓位大小。
- 20 日波动率闸门仍读 159952 的波动，再去缩放美股弹性。159952 权重是 0。
- 单资产急跌仍会看被排除的槽。v47 已经排除 159232，同样会看它。若为了跳过排除槽去改引擎，默认 v47 的结果会变，所以引擎没动。
- 美股快刹车、美股深熊锁、QDII 溢价门控和倾斜、绝对动量、3 周冷却、80/100/120 结构闸门多数投票都还在。结构闸门的美股投票仍然削减美股成长仓；A 股投票乘的是已经为 0 的国内成长仓。
