## 1. 目标与结论

用户要求：**彻底移除自由现金流 159232/159222，重新组合现有风控层，保留有效机制、删除无用机制，在控制回撤的同时提升收益**。

结论：v41 保留 v40 的收益骨架，但把释放出的国内防御槽与风险预算转向海外底仓和成长仓，并将风控层收敛为“结构闸门 + 快刹车 + 深熊锁 + QDII 溢价门控/倾斜 + 触底冷却 + 资产急跌刹车 + 绝对动量 + 波动率闸门”。点估计优于 v40，但不是全面支配：real 回撤扩大、部分历史阶段更差、自助法尾部没有改善。

## 2. 相对 v40 的改动

1. `exclude: ["159232"]`：信号槽和成交端同时排除自由现金流；`instrument_swaps` 只保留 `515100 -> 563020`，成交端不再出现 159222。
2. 国内底仓按配置口径仍是 `floor_pct.cn=2`，但该值在两槽平分后排除 159232，**实际成交端只剩 563020 的 1%**；释放出的 1% 转向海外底仓/成长仓。这是有效口径，不能把文档写成“国内底仓 2%”。
3. 海外底仓 `us: 10% -> 12%`（159941/513500 各 6%）。
4. `growth_split_bull: 32/61/7 -> 36/57/7`；状态 7/8/9 成长上限 `71.5/93.5/89.1 -> 75/95/91`。
5. `min_cash: 0.03 -> 0`，`max_eq: 0.98 -> 1.0`。
6. 保留：快刹车、深熊锁、结构闸门、QDII 溢价门控/倾斜、3 周触底冷却、资产 5 日急跌刹车、120 日绝对动量闸门、20 日波动率闸门。
7. 关闭：`defense_momentum`（只剩一个防御槽，原逻辑无数值作用）、`corr_risk`、`premium_rotate`、`us_rotation`、`regime_gate`、`recovery_ramp`、`reentry_step`、`speed_brake`。

配置：`references/final_cfg_v41.json`。回退：`references/final_cfg_v40.json`、`final_cfg_v39.json`、`final_cfg_v37.json`、`final_cfg_v30.json`。

## 7. 边界与失败项

1. real 窗口 MDD 从 -4.19% 扩大到 -4.53%，不是无代价升级。
2. 2019-21、2018、2015 股灾、2021-22 的部分阶段收益或回撤差于 v40。
3. 自助法尾部没有改善：`P(Cal<1)` 约 20%，5% 分位 MDD 约 -14.9%。
4. 国内有效底仓只有 1%，低于 v40 的名义 2%；这是排除 159232 后的真实暴露，不能按 2% 记账。
5. 回测使用净值/指数代理，未完整建模 QDII 场内溢价、滑点、涨跌停封板与跟踪误差；QDII 收益滞后 1 日的保守对照为 `27.92% / -5.51% / Cal 5.06`。
6. 511260 是久期资产，不是无风险现金；利率上行时现金层本身会回撤，而股票端风控不会响应。
7. 历史表现不代表未来，本记录不构成投资建议。
