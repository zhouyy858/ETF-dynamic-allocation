## 3. 验证

- 严格未来函数审计 `scripts/audit_lookahead_v40.py`：40 个截断/未来扰动样本最大绝对差 `0`；周五 09:00 信息集与回测决策逐项一致；`ALL ASSERTIONS PASSED`。
- 扰动审计 `scripts/audit_robustness.py references/final_cfg_v40.json v40`：104 次中 Calmar 恶化>10% 为 **4 次**，全部是 `gate_win` ±10/20%，其余轴平稳。
- 20 日块自助 2000 次：`P(Cal<1)=20.1%`（v39 为 29.8%）。
- 费用 5→10→15→20bp：proxy `13.35%→11.68%`、MDD `-7.83%→-8.35%`、Calmar `1.71→1.40`。
- 现金层冲击：511260 连续 20 日 -8% 可将 MDD 打到约 -13.4%，而股票端风控不会响应；这是现金层久期风险，不由 v40 改变。

## 4. 边界

- v40 不是严格支配 v39：real 窗口 MDD 从 -3.72% 扩大到 -4.19%，2021-22 熊与跨境共振熊略差。
- 改善集中于 2015、2019-21、2025-26；不能把这段历史外推为未来收益。
- 当前 CN 深熊锁下 v39 与 v40 目标一致，升级不产生额外交易。
- 历史表现不代表未来，本记录不构成投资建议。
