## 建议从规则里拿掉、但本 PR 不动默认

拿掉之后账本与 v40 逐位相同（换手 proxy 119.28 / real 14.57 / OOS 40.11）。相同不是改进，所以不放进默认配置。

1. **美股快刹车（回撤 13%、削减 0.12）**。阈值放到 16%，以及整段关掉，三窗与 v40 逐位相同。当前阈值没有改过任何一笔成交。收到 10% 会开始起作用，并且 OOS Calmar 降到 1.56789。建议删掉这条美股腿，不是把它收紧。
