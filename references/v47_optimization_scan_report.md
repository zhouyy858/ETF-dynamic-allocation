# v47 纸面优化扫描（2026-11-25）

默认配置不改。`references/final_cfg_v47.json` 与 `main` 上的文件相同。本报告不下单，也不把任何候选写成新的默认。

## 结论

**不更换默认。** 预注册的换券、现金替代和规则邻域里，没有任何一个在同一截止日、同一场内价口径上同时严格提高 proxy、OOS、real 三个 Calmar。

最近的失败各有不同，都不能升格：

- 日经 `159866` 的 OOS Calmar 高 0.200，但 proxy 低 0.020、real 低 0.599。OOS 的改善来自回撤从 -5.89% 收到 -5.37%，年化收益本身更低。
- 家电 `159996` 的 proxy Calmar 高 0.116，但年化从 16.09% 降到 14.38%，OOS / real 明显更差。Calmar 上升是回撤变浅，不是收益变好。
- 冷却 4 周的 OOS / real 略好（+0.004 / +0.019），proxy 更差（-0.008）。
- CN 快刹车削减从 0.05 改到 0.04 或 0.06，三个窗口的 Calmar 变化都在 ±0.001 以内，proxy 与另外两窗方向相反。

未来函数审计没有新的对象。没有任何候选走到这一关。

## 事先定下的判定

比较只用官方引擎：`DynamicStrategy` + `run_backtest(strict=True)` + `pnl_panel`，场内价口径，单边万 5，周五一笔，现金 100% `511260`（现金替代那一组除外）。v47 基线与 `python scripts/run_backtest.py references/final_cfg_v47.json v47 price` 的 proxy / real 指标一致到 1e-9。

三关的比较基准是**这次刷新后的 v47**，不是 2026-11-12 的冻结表。三个 Calmar 都要严格更高。

另外写进扫描脚本、在出结果之前就固定的筛选：

- 候选自己的行情必须在 2022-01-04 之前已经有成交，否则 OOS 会被原槽拼接，三关无效。
- 同一经济暴露至少两只场内 ETF（去掉联接）才有替代；孤品不回测。
- 近 20 日成交额中位数低于 2000 万人民币的不作为主测券。同一暴露里取得分最高、且历史覆盖 OOS 的一只，不改去挑另一只。
- QDII 在引擎当前可用的溢价日（决策日 2026-11-27，信号 2026-11-25，`premium_shift=2`，即 **2026-11-24**）原始溢价高于 8% 则否决。不改用低溢价孪生。
- 2022 年以来与被替换槽的日收益相关达到 0.90，视为近重复，即使三关通过也不升级。
- 换券是整槽 `instrument_swaps`。信号、打分、深熊锁仍用原槽面板；变的是成交损益。这和 v47 把 515100 槽换成 512890 是同一条引擎路径，不是 50/50，也不是把打分改成新资产自己的趋势。
- `run_backtest.py` 的场内价覆盖会无条件写回 159941 / 513500 两列。扫描对已经换走的槽不再写回原券价格，否则海外换券在损益上是空操作。v47 本身两列都没换，所以基线与官方脚本一致。复现换券数字要用本报告的扫描脚本，不能把换券配置直接丢进 `run_backtest.py`。

现金仍是 511260，除非替代品自己过三关。不重测 110017。`defense_momentum` 在只剩一个防御槽时是零贡献（见 `references/v41_candidate_report.md`），本轮不重开。
